# 北京出行提案

2026年10月10日市内聚会、10月18日户外一日游的商量页面。

**网站：** https://zeroplus657.github.io/beijing-outing-2026/

## 三条路线

- **10月10日 · 海淀市内线**：海淀公园 → 苏州街桌游 → 新中关火锅 → 可选 KTV。
- **10月18日 · 香山西郊线**：巴沟集合 → 香山登山 → 万柳火锅，天黑前离山。
- **10月18日 · 奥森轻松线**：市内低强度替代，南园散步 → 新奥聚餐 → 可选夜景。

日期均按完整一日活动规划。所有地点限北京市，当天往返。

## 怎么提建议

在网页选择日期与路线、填写建议，预览后前往 GitHub，登录并确认创建 Issue。网页通过 GitHub 公共接口读取建议，所有人都能查看；网络不通时也可以直接打开仓库的 Issues 页面。

没有 GitHub 账号时，可使用「复制建议发微信群」。此操作只复制文字，不会自动上传或保存为共享留言。

提交后，GitHub 账号、所填称呼和建议是公开的。不要填写手机号、微信号、住址、具体健康资料或他人的个人信息。不使用真实姓名亦可。

## 信息边界

这是可讨论的提案，不是已预订或已确认的活动。参加人数暂按15人估算，可在页面调整。预算不是商家报价，15人 KTV 容量、门店营业、套餐时段与座位必须在预订前直接确认。公园、地图与点评的参考链接列在页面中；美团实时套餐与库存未核实。
